# 📁 Proyectos

## 01 — Data Analytics & BI

### 📞 Análisis de operadores ineficaces — CallMeMaybe

Análisis de datos de llamadas para identificar operadores con señales de posible ineficiencia.

**Resultados principales:**

- 49,002 registros analizados después de la limpieza.
- 1,092 operadores evaluados.
- 188 operadores identificados bajo los criterios establecidos.
- 17.2% de los operadores clasificados como ineficaces.
- Análisis de llamadas perdidas, tiempo de espera y llamadas salientes.
- Aplicación de análisis estadístico.
- Visualización de resultados mediante Tableau.

**Tecnologías:**

`Python` `Pandas` `SciPy` `SQL` `Tableau`
